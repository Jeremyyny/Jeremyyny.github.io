# Yuning Yang

Source for [Yuning Yang’s personal website](https://jeremyyny.github.io/), built with Jekyll and the [al-folio](https://github.com/alshedivat/al-folio) theme.

The homepage introduction is in `_pages/about.md`. Publications are stored in `_bibliography/papers.bib`. GitHub Actions builds the site from `master` and publishes it to GitHub Pages.
